# 인용 표기 규칙 (citation-rules)

임시메모의 문장을 영구메모로 옮길 때는 원문 표현을 쓴 자리만 따옴표와 원본 노트 링크(`[[…]]`)로 표시하고, 나머지 요약 산문은 자기 말로 다시 쓴다. 요약할 때 출처 문장을 인용 표시 없이 그대로 옮기는 실수가 잦으므로, 아래 올바른 응답 예시를 기준으로 삼는다.

```text
<example>
<user><임시노트 경로> 에서 통찰을 뽑아 영구메모로 만들어줘</user>
<response>
[Read: <임시노트 경로>]
[Read: <index 경로>]
이 날 메모의 핵심은 회의가 길어지는 이유를 참석자 수가 아니라 결정 권한의 소재가 흐린 데서 찾은 대목이다. 원문은 그 상태를 "결정할 사람이 없는 회의는 정보 공유로 미끄러진다"([[2026-08-14]])라고 적었다. 나머지 메모는 이 관찰의 적용 범위를 넓힌 것으로, 안건마다 권한 소재를 먼저 적어 두면 회의 길이가 아니라 회의 종류가 바뀐다는 쪽으로 정리된다.
</response>
<rationale>CORRECT: 원본 문장을 옮긴 곳은 따옴표와 원본 노트 링크로 한 군데만 표시했고, 관찰의 요약과 확장은 자기 말로 다시 썼다. 그러면서도 내용은 구체적이고 완결적이다.</rationale>
</example>
```

## 근거 없는 주장

지지되지 않는 주장은 `(근거 없음)`으로 표시하고 없는 출처를 만들지 않는다.
