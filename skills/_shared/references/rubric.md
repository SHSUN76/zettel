# 5기준 채점 규칙 (rubric)

임시노트·문헌노트에서 뽑아낸 아이디어를 하나씩 다섯 기준으로 1~5점 채점한다. 채점은 LLM이 하고, 승격 여부의 최종 문지기는 `gate-rules.md`의 스크립트 게이트다. 평균 점수가 아무리 높아도 게이트가 HOLD면 승격하지 않는다.

## 평가 기준 (5가지)

각 아이디어/통찰을 1-5점으로 평가하고, **평균 ≥ `gate.pass_avg`(기본 3.5) → PASS 후보**로 본다.

| 기준 | 설명 | 높은 점수 예 | 낮은 점수 예 |
|------|------|------------|------------|
| **독립성** | 다른 메모 없이 단독으로 이해 가능한가 | 맥락 없이도 의미 전달 | 특정 상황 전제 필요 |
| **원자성** | 하나의 핵심 아이디어만 담고 있는가 | 단일 통찰, 명확한 주장 | 여러 아이디어 혼합 |
| **연결성** | 기존 영구노트와 연결점이 있는가 | `paths.index` 안에 관련 노트 존재 | 기존 지식과 무관 |
| **영속성** | 시간이 지나도 유효한 통찰인가 | 원칙, 패턴, 프레임워크 | 날짜 종속, 일회성 태스크 |
| **통찰** | 독자적 사고나 새로운 관점이 있는가 | 경험에서 도출된 원칙 | 교과서 요약, 상식 |

문헌노트를 채점할 때는 같은 다섯 기준을 문헌 맥락으로 바꿔 읽는다.

| 기준 | 문헌노트에서의 설명 | 높은 점수 예 | 낮은 점수 예 |
|------|------|------------|------------|
| **독립성** | 원문 없이 단독으로 이해 가능한가 | 맥락 없이도 의미 전달 | 원문 참조 필수 |
| **원자성** | 하나의 핵심 아이디어만 담고 있는가 | 단일 통찰, 명확한 주장 | 여러 개념 혼합 |
| **연결성** | 기존 영구노트와 연결점이 있는가 | `paths.index` 안에 관련 노트 존재 | 기존 지식과 무관 |
| **영속성** | 시간이 지나도 유효한 통찰인가 | 원칙, 이론, 프레임워크 | 시사적, 일시적 정보 |
| **통찰** | 독자적 사고나 새로운 관점이 있는가 | 저자의 핵심 주장 + 나의 해석 | 단순 인용, 요약 |

## 점수 해석

| 평균 | 해석 | 처리 |
|------|------|------|
| **4.5-5.0** | 즉시 영구노트 (강력 PASS) | 게이트 통과 시 승격 |
| **3.5-4.4** | 영구노트 적합 (PASS) | 게이트 통과 시 승격 |
| **3.0-3.4** | 경계선 — 보완하면 영구노트 가능 | 보완 제안 **1회**, 그래도 미달이면 HOLD |
| **2.0-2.9** | FAIL | **HOLD** — 파일을 옮기지 않고 원본에 표시만 남긴다 |
| **1.0-1.9** | DROP 후보 | 사용자 확인 후 폐기 기록. 파일은 지우지 않음 |

- 3.0~3.4 경계선에서 보완 제안은 한 번만 한다. 되묻기를 반복해 사용자의 문장을 대신 써 주지 않는다.
- 2.0~2.9 FAIL은 파일을 옮기지 않는다. 원본에 `status: hold`와 `review_at`만 남긴다.
- DROP은 자동으로 실행하지 않는다. 반드시 사용자 확인을 받고, 사유를 `paths.meta`의 폐기 기록 파일에 남기며, 파일 자체는 삭제하지 않는다.

## 문헌노트 특화 가산·감점

- 단순 하이라이트(밑줄만 긋고 메모 없음)는 **통찰 점수가 낮음**
- 하이라이트 + 나의 메모가 있으면 **통찰 점수 가산**
- 저자의 주장을 나의 경험/지식과 연결하면 **연결성 점수 가산**

문헌노트는 "하이라이트 + 나의 메모" 세트를 하나의 채점 단위로 삼는다. 메모 있는 하이라이트를 먼저 처리하고, 메모 없는 단독 하이라이트는 유망한 것만 후보로 올린다.

## 배치 결과 표 형식 (표준)

배치 채점이 끝나면 아래 표를 그대로 써서 결과를 제시한다.

| # | 파일 | 아이디어 | 독립성 | 원자성 | 연결성 | 영속성 | 통찰 | 평균 | 게이트 | 판정 | 번호 |
|---|------|---------|--------|--------|--------|--------|------|------|--------|------|------|
| 1 | 파일A | 핵심 통찰 요약 | 4 | 5 | 4 | 4 | 4 | 4.2 | PASS | 승격 | 1A3 |
| 2 | 파일B | 태스크 리스트 | 2 | 3 | 1 | 2 | 2 | 2.0 | — | HOLD | — |

- `게이트` 칸에는 `gate.py check`의 verdict(PASS/HOLD)를 적는다. 채점 평균이 미달이라 게이트를 돌리지 않았으면 `—`로 둔다.
- `번호` 칸은 승격이 확정된 노트만 채운다. 번호는 언제나 스크립트가 낸 값을 그대로 옮긴다.
- 마지막 줄에 `PASS n / HOLD n / DROP n. commit·push 하세요.`를 붙인다.
